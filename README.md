Ridge Runner — a 2D canvas side-scrolling flight game. Fly a plane over a procedural ridge (river valley, pine trees, a lit town, a runway) with three missions: Ring Run (thread 8 rings before fuel runs out), Courier (pick up the parcel, then land gently on the runway), and Storm Run (gusts, 5 fuel cans, land on the far strip). Fuel, damage, stall and landing rules, near-miss bonuses, and synthesised WebAudio sounds. Controls: ↑ climb · ↓ dive · → throttle up · ← throttle down · Space boost · P pause · M mute · R restart.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser.
